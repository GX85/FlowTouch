# FlowTouch для Windows

1. Установите Python 3.11 или новее (python.org). На экране установки включите Add Python to PATH.
2. Распакуйте **весь** архив в отдельную папку.
3. Запустите `Start-FlowTouch.cmd`. Откроется http://127.0.0.1:8765/studio/.
4. Подключите камеру, разрешите доступ. Проверьте жесты в тренировке.
5. Включите «Выполнять команды». Локальная студия управляет активным окном Windows.

**Escape** ставит системное управление на паузу даже вне браузера. Для продолжения снова включите переключатель. Закрытие окна помощника полностью останавливает сервер. При скрытии локальной вкладки управление останавливается и камера отключается. Для управления другим приложением держите студию видимой рядом с ним, например в отдельном окне. Не сворачивайте студию.

## Алфавит — 32 команды

Позы, свайпы и связки включаются отдельными режимами. Инструкции для всех команд есть в каталоге локальной студии. Системная громкость, медиаклавиши, управление вкладками, буфером и окнами работают в активном приложении; поведение горячих клавиш зависит от него.

Для повторения позы отпустите её минимум на 250 мс. Удержание — 800 мс. Связки: первый жест 800 мс, затем второй жест в течение 2,2 секунды. Связки не выполняют команды отдельных жестов. Открытая ладонь останавливает управление в режимах «Позы» и «Связки»; в «Свайпах» используйте Escape.

Распознавание экспериментальное. Обеспечьте свет и держите всю кисть в кадре. Порог уверенности можно изменить в настройках. Число уверенности для геометрических поз — условный порог эвристики, а не калиброванная вероятность. FPS зависит от компьютера и камеры.

## Приватность и устройство

Кадры не записываются и не передаются. Модель и WebAssembly-файлы находятся в app/. Ключи API и платные сервисы не нужны. Сервер слушает только 127.0.0.1. Команды ограничены фиксированным списком, проверяются Host/Origin и временный токен сессии. Системное управление требует явного включения и heartbeat каждые 1 секунду; таймаут — 3 секунды. Перевод курсора в верхний левый угол кадра также ставит управление на паузу.

Веб-страницы, открываемые жестом, используют интернет. Открытый YouTube может забрать фокус у студии — вернитесь в окно студии и включите управление повторно, если оно приостановилось.

Для проверки без системных действий: `python flowtouch.py --dry-run`. В этом режиме команды проверяются, но ничего не нажимают и не открывают.

## Если камера не открывается

Откройте «Не видишь камеру? Проверить подключение». Выберите источник видео либо «Автоматически» и обновите список. Проверьте камеру в стандартном приложении Windows «Камера», подключите USB напрямую в другой порт. Зелёный аналоговый аудиоштекер не передаёт видео. Если Windows не видит камеру, веб-страница не может заменить драйвер. Если в Windows камера работает, используйте системный Chrome или Edge.

Звук выключен по умолчанию; выключатель полностью закрывает аудиоконтекст. Никаких фоновых звуков приложение не генерирует.
