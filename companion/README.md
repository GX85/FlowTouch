# FlowTouch Studio 2.1 — Windows

Распакуйте весь архив, сохраняя папку _internal рядом с FlowTouch Studio.exe.
Запустите FlowTouch Studio.exe. Python уже включён в сборку.
Нужны Windows 10/11, .NET Framework 4.6.2+ и Microsoft Edge WebView2 Runtime.
Официальный WebView2: https://developer.microsoft.com/microsoft-edge/webview2/

1. Подключите камеру и разрешите доступ по запросу.
2. Проверьте жесты. В настройках есть проверка модели на контрольном фото;
   она не проверяет живую камеру.
3. Выберите профиль. Geometry Dash включает быстрый ввод: щепотка держит Space,
   отпускание жеста отпускает клавишу, кулак нажимает Space однократно.
4. Включите «Начать управление Windows» и переключитесь в целевую программу.
5. Escape — глобальная пауза. Закройте Studio, чтобы остановить сервер и камеру.

126 шаблонов: 12 поз, 4 свайпа, 110 двухшаговых последовательностей.
Это не 126 разных положений пальцев. Для повторения позы отпустите её на 250 мс.
Геометрические позы экспериментальные; важны освещение и положение кисти.
Windows может запрещать ввод в защищённые игры и приложения с повышенными правами.

Звуки выключены по умолчанию. Кнопка звука открывает щелчки клавиатуры,
тихий атмосферный фон и независимые регуляторы. Клавиши звучат только внутри Studio.

Агент необязателен. Offline observer работает без сети и не является LLM.
OpenRouter/Ollama используют модель и ключ из локальных настроек.
Ключи шифруются Windows DPAPI, кадры не передаются агенту.

Эта сборка не подписана сертификатом издателя. SmartScreen может показать предупреждение;
отключать защиту не требуется и не рекомендуется. SHA-256 архива опубликован рядом со скачиванием.
Журнал ошибок запуска: %LOCALAPPDATA%/FlowTouch/studio.log
Данные модели и интерфейса входят в папку _internal/app, интернет для распознавания не нужен.
Исходный код: https://github.com/GX85/FlowTouch
